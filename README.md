# DSA Notes

My notes on data structures and algorithms in C++, organized by problem-solving pattern and written in [Obsidian](https://obsidian.md).

## How to read

- **On GitHub:** start from one of the hubs below. Links inside the notes use Obsidian's `[[wikilink]]` format, which GitHub shows as plain text, so use this page to get around.
- **In Obsidian (full experience):** clone the repo and open the folder as a vault. You get working links, backlinks and the graph view.

```
git clone https://github.com/Nihar-Shah2001/dsa-notes.git
```

## Adding a note

1. For a problem, create the note from `Templates/Problem.md` and save it in `Patterns/`. STL notes go in `STL/`.
2. Fill in its pattern, topics, prerequisite, related and next-concept links.
3. Add it to [Map of Patterns](Map%20of%20Patterns.md) under its topic, or link it from [STL Map](STL/STL%20Map.md), and add it to the list above.
