# Map of Patterns

The topic-wise order for the whole journey. Each link is a pattern note to write after you learn it; links to notes that do not exist yet show up as faint nodes in the graph, so the graph fills in as you write.

**How to use:** finish a topic across every problem sheet before moving on. When a pattern clicks, create its note from the **Pattern** template, link it to its prerequisites and to the patterns it combines with, then tick it here.
